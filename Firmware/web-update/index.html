Prepare the SD card

        

          
Back up the SD card first. Formatting deletes all files on it.

          
Windows: cards up to 32 GB

          
    
            
  1. Insert the SD card and open File Explorer.
    2. 
            
  2. Right-click the SD card drive and select Format.
    3. 
            
  3. Select FAT32 and Default allocation size, then click Start. Check the drive letter carefully.
    4. 
          

          
Alternative and cards over 32 GB

          
The SD Memory Card Formatter is another option for cards up to 32 GB. For larger cards it normally uses exFAT, so use Rufus and select Large FAT32 instead.
